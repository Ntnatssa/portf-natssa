Portfólio profissional desenvolvido do zero com **HTML, CSS e JavaScript puro** (sem frameworks), com foco em performance, acessibilidade e experiência do usuário.

## ✨ Funcionalidades

- 🌍 **Trilíngue** — português, inglês e espanhol (troca instantânea)
- 🌗 **Modo claro/escuro** — com persistência da escolha (localStorage)
- ✨ **Animações** — efeito de digitação no hero, reveal ao rolar, barras de habilidades animadas
- 🎯 **Navegação por bolinhas laterais** com scroll spy + barra de progresso de rolagem
- 🌌 **Parallax** nos elementos de fundo
- 📱 **100% responsivo** para celular, tablet e desktop
- 📨 Seção de contato com e-mail, GitHub e LinkedIn

## 🛠️ Stack

- **Frontend:** HTML5, CSS3, JavaScript (vanilla), Tailwind CSS (CDN), Remix Icon
- **Fonte:** Archivo (Google Fonts)
- **Habilidades destacadas:** Node.js & Express · React & Hooks · JavaScript/ES6+ · MariaDB · PostgreSQL · SQL · Tailwind CSS · Git & GitHub · APIs REST

## 🚀 Como rodar localmente

Opção 1 (mais simples): dê **duplo clique** no `index.html` — abre direto no navegador.

Opção 2 (com servidor local, requer Node.js):

```bash
npx serve .
# depois abra http://localhost:3000
```
